# textkit

## วัตถุประสงค์

ชุดฟังก์ชันพื้นฐานสำหรับจัดการข้อความ พัฒนาโดยสมาชิกทีม 4 คน

## การใช้งาน

```bash
python3 main.py
```

## โมดูล

### counter.py (สมาชิก 1)

ยังไม่ได้เขียน

### reverser.py (สมาชิก 2)

ฟังก์ชัน `reverse_words(text)` กลับลำดับคำ เช่น `reverse_words("hello first year")` ได้ `year first hello`

### cleaner.py (สมาชิก 3)

ยังไม่ได้เขียน

### caser.py (สมาชิก 4)

ฟังก์ชัน `capitalize_words(text)` ทำให้อักษรตัวแรกของแต่ละคำเป็นตัวพิมพ์ใหญ่ เช่น `capitalize_words("hello first year")` ได้ `"Hello First Year"`Example: capitalize_words(hello first year) returns Hello First Year.
